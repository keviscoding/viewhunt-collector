# Sound Effects

Drop your 3 SFX files here (mp3 or wav):

1. `transition.mp3` — Click/whoosh that plays on scene transitions (randomly, not every time)
2. `hook.mp3` — Punchy sound that plays on each hook cut (the rapid 0.5s clips at the start)
3. `riser.mp3` — Rising tension sound that plays right before the first body clip starts (after the hook ends)

The video editor will automatically pick these up during assembly.
